# Forgotten Snowman Mod

Add a powerful Forgotten Snowman boss to your Minecraft world with unique abilities and loot.

## Features

- New boss mob with 300 HP and 6-12 damage attacks
- Unique abilities like Snow Slam and Ice Blizzard
- Custom blocks and items including Frost Heart, Ice Shard, and Snowball
- Advancements for defeating the boss and crafting items

## Requirements

- Minecraft 1.21.4
- Forge 47.1.0 or later

## Installation

1. Download the latest release from the Releases page
2. Place the JAR file in your `mods` folder
3. Launch Minecraft with Forge

## Usage

### Spawning the Boss

- Craft a Forgotten Snowman Spawn Egg using snowballs and eggs
- Place the spawn egg to summon the boss

### Abilities

- **Snow Slam**: A powerful ground attack
- **Ice Blizzard**: A freezing area effect

### Loot

- Frost Heart: Dropped by the boss
- Ice Shard: Found in Ice Ore blocks
- Snowball: Basic crafting material

## Configuration

The mod includes several configuration options:

- Boss health and damage
- Ability cooldowns
- Block and item properties

Configuration files are located in the `config/forgottensnowmanmod` directory.
